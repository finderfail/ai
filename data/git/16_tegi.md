# Git: теги и версии

```bash
git tag                         # список тегов
git tag v1.2.0                  # лёгкий тег на текущий коммит
git tag -a v1.2.0 -m "Релиз 1.2.0"   # аннотированный тег (рекомендуется)
git tag -a v1.1.0 abc1234 -m "..."   # тег на старый коммит
git push origin v1.2.0          # отправить один тег
git push --tags                 # отправить все теги
git tag -d v1.2.0               # удалить локально
git push origin --delete v1.2.0 # удалить на сервере
git switch --detach v1.2.0      # посмотреть код версии
```

По умолчанию `git push` теги не отправляет. Для версий обычно используют семантическое версионирование: MAJOR.MINOR.PATCH.
