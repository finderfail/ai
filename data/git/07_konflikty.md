# Git: разрешение конфликтов

При конфликте git помечает спорные места в файле:

```
<<<<<<< HEAD
ваша версия
=======
входящая версия
>>>>>>> feature/login
```

Порядок действий:
1. `git status` — список файлов с конфликтами.
2. Откройте каждый файл, оставьте нужный вариант, удалите маркеры `<<<<<<<`, `=======`, `>>>>>>>`.
3. `git add файл` — отметить конфликт решённым.
4. `git commit` (при merge) или `git rebase --continue` (при rebase).

Взять целиком одну сторону: `git checkout --ours файл` или `git checkout --theirs файл`. Передумали — `git merge --abort` / `git rebase --abort`.
