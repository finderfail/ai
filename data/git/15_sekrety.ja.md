# Git：リポジトリに秘密情報が入ってしまったら

パスワード、トークン、API キーをコミットしてサーバーに送ってしまった場合は、漏えいしたものとみなします。

1. ただちにサービス側でその秘密情報を無効化・変更します（新しいキーを発行）。これが最重要です。履歴から消しても、すでにコピーされた可能性は消えません。
2. コードから秘密情報を取り除いて `.env` に移し、`.env` を `.gitignore` に追加します。
3. 必要なら `git filter-repo` や BFG Repo-Cleaner で履歴から消し、`git push --force` します。全員がクローンし直す必要があるので、チームと調整してください。

まだ push していなければ、`git reset --soft HEAD~1` か `git commit --amend` で十分です。
