# Git: восстановление потерянного — reflog

`git reflog` хранит, куда указывал HEAD за последнее время (по умолчанию около 90 дней), даже после `reset --hard`, неудачного rebase или удаления ветки.

```bash
git reflog                       # список: HEAD@{0}, HEAD@{1}, …
git reset --hard HEAD@{2}        # вернуть ветку в то состояние
git switch -c rescue abc1234     # или создать ветку из найденного коммита
git branch restored abc1234      # восстановить удалённую ветку
```

reflog локальный: на другом компьютере и на сервере его нет. Незакоммиченные изменения, удалённые `git restore` или `reset --hard`, reflog не спасёт.
