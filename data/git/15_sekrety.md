# Git: если в репозиторий попал секрет

Если пароль, токен или ключ API закоммичен и отправлен на сервер — считайте его скомпрометированным.

1. Немедленно отзовите или смените секрет у сервиса (сгенерируйте новый ключ). Это главное: удаление из истории не отменяет того, что секрет уже могли скопировать.
2. Уберите секрет из кода, вынесите его в `.env` и добавьте `.env` в `.gitignore`.
3. При необходимости вычистите его из истории инструментом `git filter-repo` или BFG Repo-Cleaner и сделайте `git push --force` — согласуйте это с командой, всем придётся переклонировать репозиторий.

Если коммит ещё не запушен — достаточно `git reset --soft HEAD~1` или `git commit --amend`.
