# Git：よいコミットメッセージ

- 1行目は50〜72文字程度で、コミットが何をするかを簡潔に書く。
- チームで文体をそろえる：「メールアドレスの検証を追加」「Fix login redirect」。
- 1行目の後に空行を入れ、必要なら詳細（なぜ・何のために）を書く。
- 1コミットに1つの論理的な変更。

よく使われる規約 Conventional Commits：
```
feat: メールでのログインを追加
fix: 空のパスワードでのクラッシュを修正
docs: README を更新
refactor: 検証処理を別モジュールに分離
```

悪い例：「fix」「修正」「wip」「asdf」。
