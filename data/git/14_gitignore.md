# Git: .gitignore

Файл `.gitignore` в корне репозитория перечисляет то, что git не должен отслеживать.

```
node_modules/
.venv/
__pycache__/
*.log
.env
dist/
.DS_Store
!keep.log
```

`/` в конце — только каталог, `*` — любые символы, `!` — исключение из правила.

`.gitignore` не действует на уже отслеживаемые файлы. Чтобы перестать отслеживать файл, оставив его на диске: `git rm --cached .env`, затем коммит. Проверить, какое правило игнорирует файл: `git check-ignore -v путь`.
