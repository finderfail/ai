# Git: хорошие сообщения коммитов

- Первая строка — до ~50–72 символов, кратко и по сути: что делает коммит.
- Повелительное наклонение или единый стиль команды: «Добавить проверку email», «Fix login redirect».
- После первой строки — пустая строка, затем при необходимости подробности: зачем и почему.
- Один коммит — одно логическое изменение.

Популярное соглашение Conventional Commits:
```
feat: добавить вход по email
fix: исправить падение при пустом пароле
docs: обновить README
refactor: вынести валидацию в отдельный модуль
```

Плохие примеры: «fix», «правки», «wip», «asdf».
