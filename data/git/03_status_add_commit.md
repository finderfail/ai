# Git: основной цикл — status, add, commit

```bash
git status                 # что изменено, что в индексе
git add file.py            # добавить файл в индекс (stage)
git add .                  # добавить все изменения в текущей папке
git add -p                 # выбрать изменения по кусочкам
git commit -m "Добавить валидацию email"
git commit -am "..."       # add + commit для уже отслеживаемых файлов
```

Три состояния: рабочая папка → индекс (`git add`) → коммит (`git commit`). Новые файлы `commit -a` не захватывает — их нужно сначала `git add`.

Коммитьте небольшими логически цельными порциями.
