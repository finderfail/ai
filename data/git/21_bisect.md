# Git: найти коммит с ошибкой — bisect

`git bisect` двоичным поиском находит коммит, после которого появилась ошибка.

```bash
git bisect start
git bisect bad                # текущая версия сломана
git bisect good v1.4.0        # эта версия работала
# git переключает на коммит посередине — проверьте и отметьте:
git bisect good               # или git bisect bad
# … повторять, пока git не назовёт виновный коммит
git bisect reset              # вернуться обратно
```

Автоматически: `git bisect run ./test.sh` — скрипт должен возвращать 0, если всё хорошо, и не 0, если ошибка есть.
