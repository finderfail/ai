# Git: отменить коммиты — reset и revert

```bash
git reset --soft HEAD~1    # отменить коммит, изменения остаются в индексе
git reset HEAD~1           # (--mixed) изменения остаются в файлах, не в индексе
git reset --hard HEAD~1    # удалить коммит и все его изменения
git revert abc1234         # создать новый коммит, отменяющий abc1234
```

Если коммит уже запушен в общую ветку — используйте `git revert`: он не переписывает историю и безопасен для коллег.

`reset` подходит для локальных, ещё не отправленных коммитов. `reset --hard` уничтожает незакоммиченные изменения; случайно потерянные коммиты обычно можно найти через `git reflog`.
