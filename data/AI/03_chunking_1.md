# Чанкинг: как правильно резать текст для RAG — часть 1

## Зачем резать документы на куски

Модель эмбеддингов и языковая модель имеют ограничение по длине входа, и чем длиннее кусок текста, тем более "размытым" получается его эмбеддинг (он усредняет смысл всего куска). Поэтому документы режут на чанки — небольшие фрагменты, каждый из которых по возможности несёт одну законченную мысль.

## Типичные стратегии чанкинга

- **По размеру символов/токенов** с фиксированным окном и перекрытием (overlap) — простой и предсказуемый способ, но может разрезать мысль посередине.
- **По структуре документа** — по абзацам, заголовкам, пунктам списка — сохраняет смысловую целостность лучше, чем чанкинг вслепую по числу символов.
- **Один факт — один чанк** — самый надёжный подход для баз знаний с чёткими фактами (имена, определения, короткие правила): каждый чанк отвечает на один конкретный вопрос, без соседних фактов на другую тему.
