# RAG と fine-tuning の比較 — その3

## どちらを選ぶか

- 頻繁に更新される事実（参考情報、ナレッジベース、ドキュメント）が必要 → RAG。
- 回答の話し方、出力形式、特定のふるまいを変えたい → fine-tuning（多くは LoRA）。
- 両方が必要 → 組み合わせます。LoRA が文体や形式を変え、RAG が最新の事実を供給します。両者は排他的ではありません。

## CPU 上の小さなモデルで RAG が選ばれる理由

LoRA でも fine-tuning にはデータセットでの学習ループ（順伝播＋逆伝播＋オプティマイザの更新）が必要で、GPU のない CPU では 0.5〜1B パラメータのモデルでも非常に遅くなります。RAG は通常の推論の前に検索（埋め込みは数ミリ秒）を加えるだけなので、通常のリクエストと比べてコストはほとんど増えません。
