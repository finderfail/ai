# Типичные ошибки при построении RAG — часть 1

## Отсутствие порога релевантности

Если брать top-K найденных чанков без проверки их фактического сходства с запросом, модель будет получать контекст даже на вопросы, к которым база знаний вообще не относится (например, простое приветствие) — из-за этого модель может начать пересказывать случайный кусок базы знаний вместо обычного ответа.

## Слишком общий контекст в одном чанке

Один большой чанк, покрывающий сразу несколько разных подтем, при поиске находится для любой из этих подтем целиком — и модель получает лишний, не относящийся к вопросу материал, который может её сбить.
