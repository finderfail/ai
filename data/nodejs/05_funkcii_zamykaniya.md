# JavaScript: функции, стрелочные функции, замыкания, this

```javascript
function sum(a, b = 0, ...rest) {
  return a + b + rest.reduce((s, x) => s + x, 0);
}

const double = (x) => x * 2;

function counter() {
  let value = 0;
  return () => ++value;
}
const next = counter();
next(); next();
```

- **Параметры по умолчанию** и **rest** (`...rest`) заменяют `arguments`.
- **Замыкание** — функция «помнит» переменные области, где была создана (`value` в примере живёт между вызовами). Основа приватного состояния, фабрик, мемоизации.
- **this** в обычной функции зависит от способа вызова (`obj.method()` → `obj`; просто `fn()` → `undefined` в строгом режиме). Стрелочные функции не имеют своего `this` и берут его из внешней области — удобно в колбэках.
- `fn.bind(obj)`, `fn.call(obj, a)`, `fn.apply(obj, [a])` явно задают `this`.
- Функции — объекты первого класса: их можно передавать, возвращать, хранить в переменных.
