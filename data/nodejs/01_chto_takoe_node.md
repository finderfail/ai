# Node.js: что это и как устроен

**Node.js** — среда выполнения JavaScript вне браузера. Состоит из:
- **V8** — JavaScript-движок от Google (тот же, что в Chrome), компилирует JS в машинный код;
- **libuv** — цикл событий, асинхронный ввод-вывод и пул потоков (файлы, DNS, crypto);
- **стандартной библиотеки**: `node:fs`, `node:http`, `node:path`, `node:crypto`, `node:stream`, `node:events` и др.

Главная идея — **один поток JavaScript + неблокирующий ввод-вывод**. Пока сервер ждёт ответа базы или сети, он обрабатывает другие запросы. Поэтому Node хорош для I/O-нагруженных задач (API, прокси, чаты, стриминг), но тяжёлые вычисления в основном потоке блокируют всех.

В Node нет `window` и DOM; глобальный объект — `globalThis` (он же `global`). Есть `process`, `Buffer`, `fetch` (с Node 18), `setTimeout`, `structuredClone`, `URL`, `AbortController`.

Для продакшена берите актуальную LTS-версию (чётные мажорные версии; см. nodejs.org).
