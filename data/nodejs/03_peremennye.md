# JavaScript: переменные, области видимости, hoisting

```javascript
const PORT = 3000;
let count = 0;
var legacy = 'не используйте var';
```

- **const** — нельзя переприсвоить (но объект внутри можно менять: `const a = []; a.push(1)` — работает). Используйте по умолчанию.
- **let** — переменная, которую будете менять.
- **var** — устаревший: область видимости функции, а не блока, «всплывает» со значением `undefined`.

Области видимости: глобальная, модульная (каждый файл — свой модуль), функциональная, **блочная** (`{ }`, `if`, `for`) — для `let`/`const`.

**Hoisting**: объявления поднимаются вверх области. `function`-декларации доступны до объявления. `let`/`const` до объявления находятся во «временной мёртвой зоне» (TDZ) — обращение даёт `ReferenceError`.

```javascript
for (let i = 0; i < 3; i++) setTimeout(() => console.log(i));
```
Выведет 0, 1, 2. С `var` было бы 3, 3, 3 — классическая ошибка замыканий в циклах.
