# Node.js: безопасность кода

- **Инъекция команд**: не передавайте пользовательский ввод в `exec`; используйте `execFile`/`spawn` с массивом аргументов.
- **Path traversal**: путь из запроса (`../../etc/passwd`) нормализуйте и проверяйте, что он внутри разрешённой папки:
```javascript
const full = path.resolve(BASE_DIR, userPath);
if (!full.startsWith(BASE_DIR + path.sep)) throw new Error('Доступ запрещён');
```
- **Prototype pollution**: не сливайте в объекты непроверенный JSON с ключами `__proto__`, `constructor`; используйте `Object.create(null)` или `Map` для словарей и валидацию схемой.
- **eval и new Function** с внешними данными — никогда.
- **ReDoS**: сложные регулярки на пользовательском вводе могут повесить цикл событий; ограничивайте длину ввода.
- **Зависимости**: `npm audit`, lock-файл, `npm ci`, проверяйте имена пакетов (тайпсквоттинг).
- **Секреты** — в переменных окружения, сравнение — `crypto.timingSafeEqual`.
- Запускайте процесс не от root.
