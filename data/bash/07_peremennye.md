# Bash: переменные

```bash
name="Ilya"            # без пробелов вокруг =
echo "Привет, $name"
echo "${name}_backup"  # фигурные скобки отделяют имя
files=$(ls)            # подстановка вывода команды
count=$((3 + 4))       # арифметика
export PATH="$HOME/bin:$PATH"   # переменная окружения для дочерних процессов
unset name             # удалить переменную
echo "${VAR:-default}" # значение по умолчанию, если VAR пуста
```

`name = "x"` с пробелами — ошибка: bash ищет команду `name`. Переменные без `export` не видны запущенным программам.
