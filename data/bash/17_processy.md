# Bash: процессы и задания

```bash
ps aux | grep node       # найти процесс
pgrep -fl node           # то же короче
top                      # нагрузка в реальном времени (htop — удобнее)
kill 1234                # попросить процесс завершиться (SIGTERM)
kill -9 1234             # убить принудительно (SIGKILL), крайний случай
pkill -f "python app.py" # завершить по имени/командной строке
lsof -i :8000            # кто занимает порт 8000

long_task &              # запустить в фоне
jobs                     # фоновые задания текущей оболочки
fg %1                    # вернуть задание на передний план
nohup ./server.sh > out.log 2>&1 &   # не умирает после выхода из терминала
```

Ctrl+C — прервать, Ctrl+Z — приостановить (потом `bg` или `fg`).
