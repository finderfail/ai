# Bash: конвейеры (pipes)

Символ `|` передаёт вывод одной команды на вход следующей.

```bash
ls -l | wc -l                          # сколько строк в выводе ls
cat access.log | grep 500 | wc -l      # сколько строк с 500
ps aux | grep python                   # найти процессы python
history | tail -20                     # последние 20 команд
sort names.txt | uniq -c | sort -rn    # частота строк по убыванию
```

`uniq` убирает только соседние повторы, поэтому перед ним почти всегда нужен `sort`.

По умолчанию код возврата конвейера — код последней команды. `set -o pipefail` делает так, чтобы ошибка в любом звене провалила весь конвейер.
