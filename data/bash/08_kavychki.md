# Bash: кавычки и экранирование

- Двойные кавычки `"..."` — переменные и `$(...)` раскрываются, пробелы сохраняются: `echo "$HOME"`.
- Одинарные `'...'` — всё буквально, ничего не раскрывается: `echo '$HOME'` выведет `$HOME`.
- Обратный слеш экранирует один символ: `echo \$5`.

Всегда берите переменные в двойные кавычки: `rm "$file"`, а не `rm $file`. Без кавычек имя `my file.txt` разобьётся на два аргумента, а `*` раскроется в список файлов.

```bash
for f in *.txt; do
  wc -l "$f"
done
```
