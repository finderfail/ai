# Bash: навигация по файловой системе

```bash
pwd              # где я сейчас
ls -la           # список файлов, включая скрытые, с правами и размерами
ls -lh           # размеры в удобном виде (K, M, G)
cd /path/to/dir  # перейти в каталог
cd ..            # на уровень выше
cd ~             # в домашний каталог (или просто cd)
cd -             # вернуться в предыдущий каталог
tree -L 2        # дерево на 2 уровня (если установлен tree)
```

`~` — домашний каталог, `.` — текущий, `..` — родительский. Пути с пробелами берите в кавычки: `cd "My Documents"`.
