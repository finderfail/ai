# Bash：ファイル内容の表示

```bash
cat file.txt         # ファイル全体を表示
less file.txt        # ページ単位で表示（q で終了、/ で検索）
head -n 20 file.txt  # 先頭20行
tail -n 20 file.txt  # 末尾20行
tail -f app.log      # 追記をリアルタイムで表示
wc -l file.txt       # 行数
wc -w file.txt       # 単語数
du -sh dir/          # ディレクトリのサイズ
df -h                # ディスクの空き容量
file image.png       # ファイルの種類を判定
```
