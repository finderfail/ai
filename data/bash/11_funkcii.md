# Bash: функции

```bash
greet() {
  local name="$1"          # local — переменная только внутри функции
  echo "Привет, $name"
  return 0                 # код возврата 0..255, не значение
}

greet "мир"

sum() { echo $(( $1 + $2 )); }
result=$(sum 2 3)          # «вернуть» значение — через echo
```

Аргументы: `$1`, `$2`, … , все — `"$@"`, количество — `$#`. `return` задаёт только код успеха/ошибки; данные возвращайте выводом и `$(...)`. Без `local` переменные функции видны всему скрипту.
