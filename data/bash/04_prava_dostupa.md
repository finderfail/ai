# Bash: права доступа chmod и chown

`ls -l` показывает права вида `-rwxr-xr--`: владелец, группа, остальные; r — чтение (4), w — запись (2), x — выполнение (1).

```bash
chmod +x script.sh        # сделать исполняемым
chmod 644 file.txt        # rw-r--r-- : обычный файл
chmod 755 script.sh       # rwxr-xr-x : скрипт или каталог
chmod 600 ~/.ssh/id_ed25519   # приватный ключ: только владелец
chmod -R u+w dir/         # рекурсивно добавить запись владельцу
sudo chown user:group file    # сменить владельца и группу
```

Ошибка `Permission denied` при запуске `./script.sh` обычно значит, что нет права `x`. Не ставьте `chmod 777` «чтобы заработало» — это открывает файл всем на запись.
