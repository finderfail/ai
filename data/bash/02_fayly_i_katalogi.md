# Bash: создание, копирование, перемещение, удаление

```bash
mkdir -p a/b/c          # создать вложенные каталоги
touch file.txt          # создать пустой файл / обновить время
cp src.txt dst.txt      # копировать файл
cp -r dir/ backup/      # копировать каталог рекурсивно
mv old.txt new.txt      # переименовать или переместить
rm file.txt             # удалить файл
rm -r dir/              # удалить каталог с содержимым
rmdir empty_dir         # удалить пустой каталог
```

`rm` удаляет безвозвратно, корзины нет. Перед `rm -rf` проверяйте путь и переменные: `rm -rf "$DIR"/` при пустой `$DIR` превратится в `rm -rf /`. Используйте `rm -ri` для подтверждения каждого файла.
