# Bash: частые ошибки

- Пробелы вокруг `=`: `x = 1` — ошибка, нужно `x=1`.
- Переменные без кавычек: `rm $f` ломается на именах с пробелами — пишите `rm "$f"`.
- `command not found` — программа не установлена или её нет в `$PATH`; проверить: `command -v prog`.
- `Permission denied` при запуске скрипта — нет `chmod +x`; при записи файла — нет прав на каталог.
- `bad interpreter: /bin/bash^M` — у файла окончания строк Windows (CRLF); исправить: `sed -i 's/\r$//' script.sh` или `dos2unix`.
- `[: missing ]` — нет пробела перед `]` в условии.
- Изменения в `~/.bashrc` не видны — выполните `source ~/.bashrc` или откройте новый терминал.
- `cd` внутри скрипта не меняет каталог вашей оболочки — скрипт работает в отдельном процессе.
