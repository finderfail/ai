# Bash：関数

```bash
greet() {
  local name="$1"          # local：関数内だけの変数
  echo "こんにちは、$name"
  return 0                 # 終了コード 0..255（値ではない）
}

greet "世界"

sum() { echo $(( $1 + $2 )); }
result=$(sum 2 3)          # 値は echo で「返す」
```

引数は `$1`、`$2`…、すべては `"$@"`、個数は `$#` です。`return` は成功／失敗のコードだけを返します。データは出力と `$(...)` で受け取ります。`local` を付けないと関数の変数はスクリプト全体から見えます。
