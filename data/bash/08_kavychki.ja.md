# Bash：引用符とエスケープ

- ダブルクォート `"..."`：変数や `$(...)` は展開され、空白は保持されます：`echo "$HOME"`。
- シングルクォート `'...'`：すべて文字どおりで何も展開されません：`echo '$HOME'` は `$HOME` と表示。
- バックスラッシュは1文字をエスケープします：`echo \$5`。

変数は常にダブルクォートで囲みましょう：`rm $file` ではなく `rm "$file"`。囲まないと `my file.txt` は2つの引数に分かれ、`*` はファイル一覧に展開されます。

```bash
for f in *.txt; do
  wc -l "$f"
done
```
