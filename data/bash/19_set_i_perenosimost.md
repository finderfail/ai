# Bash: bash, sh и zsh — что учитывать

- `#!/bin/sh` — POSIX-оболочка: нет `[[ ]]`, массивов, `{1..5}`, `$((...))` работает. На Ubuntu `sh` — это dash.
- `#!/usr/bin/env bash` — bash со всеми расширениями. Используйте его, если пишете на bash.
- macOS по умолчанию использует zsh, а системный bash там старый (3.2): нет ассоциативных массивов и `${var,,}`. Новый ставится через `brew install bash`.
- Утилиты различаются: GNU (Linux) и BSD (macOS) `sed`, `date`, `grep` имеют разные флаги. Например `date -d` есть только в GNU.

Проверить скрипт на ошибки помогает `shellcheck script.sh`.
