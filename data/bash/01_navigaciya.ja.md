# Bash：ファイルシステム内の移動

```bash
pwd              # 現在のディレクトリ
ls -la           # 隠しファイルを含む一覧（権限・サイズ付き）
ls -lh           # サイズを読みやすく表示（K, M, G）
cd /path/to/dir  # ディレクトリへ移動
cd ..            # 1つ上の階層へ
cd ~             # ホームディレクトリへ（cd だけでも可）
cd -             # 直前のディレクトリへ戻る
tree -L 2        # 2階層分のツリー表示（tree がある場合）
```

`~` はホーム、`.` は現在、`..` は親ディレクトリです。空白を含むパスは引用符で囲みます：`cd "My Documents"`。
