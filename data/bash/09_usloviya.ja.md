# Bash：条件分岐 if と test

```bash
if [[ -f "config.yml" ]]; then
  echo "ファイルがあります"
elif [[ -d "config" ]]; then
  echo "ディレクトリです"
else
  echo "どちらもありません"
fi
```

`[[ ]]` でよく使う判定：
- `-f パス` 通常ファイル、`-d` ディレクトリ、`-e` 存在する、`-x` 実行可能
- `-z "$s"` 空文字列、`-n "$s"` 空でない
- `"$a" == "$b"`、`"$a" != "$b"` 文字列の比較
- `$x -eq 5`、`-ne`、`-lt`、`-le`、`-gt`、`-ge` 数値の比較

算術には `(( x > 5 ))` が便利です。`[[ ` と ` ]]` の内側の空白は必須です。
