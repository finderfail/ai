# Bash: условия if и test

```bash
if [[ -f "config.yml" ]]; then
  echo "файл есть"
elif [[ -d "config" ]]; then
  echo "это каталог"
else
  echo "нет ни файла, ни каталога"
fi
```

Частые проверки внутри `[[ ]]`:
- `-f путь` — обычный файл, `-d` — каталог, `-e` — существует, `-x` — исполняемый
- `-z "$s"` — строка пустая, `-n "$s"` — непустая
- `"$a" == "$b"`, `"$a" != "$b"` — строки
- `$x -eq 5`, `-ne`, `-lt`, `-le`, `-gt`, `-ge` — числа

Для арифметики удобнее `(( x > 5 ))`. Пробелы внутри `[[ ` и ` ]]` обязательны.
