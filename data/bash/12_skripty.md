# Bash: как написать и запустить скрипт

```bash
#!/usr/bin/env bash
set -euo pipefail

main() {
  echo "Аргументы: $*"
}

main "$@"
```

Запуск: `chmod +x script.sh && ./script.sh арг1 арг2` или `bash script.sh`.

`set -e` — выйти при первой ошибке, `-u` — ошибка при обращении к неопределённой переменной, `-o pipefail` — ошибка в любой части конвейера. Это защищает от тихих сбоев.

Аргументы скрипта: `$0` — имя, `$1..$9` — позиционные, `"$@"` — все по отдельности, `$#` — количество. Код выхода задаётся `exit N`.
