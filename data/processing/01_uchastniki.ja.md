# プロセシング：カード決済の参加者

- **カード会員**：購入者。
- **加盟店**（merchant）：支払いを受け付ける店。
- **イシュア**（発行銀行）：カードを発行し、会員の口座を管理し、取引を承認または拒否する。
- **アクワイアラ**（加盟店契約会社）：加盟店を担当し、端末の設置やオンライン決済の接続を行い、加盟店に売上を入金する。
- **決済ブランド**（スキーム）：Visa、Mastercard、Mir など。ルール、ブランド、イシュアとアクワイアラを結ぶネットワーク。
- **プロセッサ**（処理センター）：取引を技術的に処理し、オーソリを中継し、清算を行う。銀行の一部門の場合も外部企業の場合もある。
- **決済代行 / PSP**（ペイメントサービスプロバイダ）：ネットショップを1つの API でカード決済につなぐ。自らアクワイアラであったり、複数のアクワイアラと接続していたりする。

同じ銀行が自行の顧客にはイシュア、自行の加盟店にはアクワイアラとなることも多い。
