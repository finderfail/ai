# CSS: подключение, каскад и специфичность

Подключение:
```html
<link rel="stylesheet" href="styles.css">
<style> p { color: #333; } </style>
<p style="color: red">inline-стиль</p>
```

**Каскад** решает, какое правило применится, если их несколько:
1. Важность: `!important` сильнее обычных правил.
2. Происхождение и слои (`@layer`): стили автора сильнее стилей браузера.
3. **Специфичность** селектора.
4. Порядок: при равенстве побеждает правило, объявленное позже.

**Специфичность** считается тройкой (ID, классы, теги):
- `#menu` → (1,0,0); `.btn`, `[type="text"]`, `:hover` → (0,1,0); `p`, `::before` → (0,0,1).
- `#nav .item a` → (1,1,1) сильнее, чем `.nav .item a` → (0,2,1).
- Inline-стиль `style="..."` сильнее любых селекторов.

**Наследование**: шрифт, цвет, `line-height` наследуются потомками; `margin`, `padding`, `border`, `background` — нет. Значения `inherit`, `initial`, `unset`, `revert` управляют этим явно.

Избегайте `!important` и ID в стилях.
