# CSS: единицы, calc() и переменные

**Единицы:**
- `px` — пиксели CSS;
- `%` — от размера родителя;
- `em` — от размера шрифта элемента (в `font-size` — от родителя);
- `rem` — от размера шрифта корня `html` (обычно 16px) — удобно для адаптивных отступов и шрифтов;
- `vw`, `vh` — 1% ширины/высоты окна; `dvh`, `svh`, `lvh` — учитывают панели браузера на мобильных;
- `ch` — ширина символа «0», удобно для ширины текста: `max-width: 65ch`;
- `fr` — доля в Grid.

**Функции:**
```css
.box { width: calc(100% - 2rem); }
h1 { font-size: clamp(1.5rem, 4vw, 3rem); }   /* минимум, предпочтительное, максимум */
.col { width: min(100%, 700px); }
```

**Пользовательские свойства (переменные):**
```css
:root {
  --brand: #7b5cff;
  --gap: 16px;
}
.button { background: var(--brand); padding: var(--gap, 12px); }
@media (prefers-color-scheme: dark) { :root { --brand: #9c84ff; } }
```
Переменные наследуются, их можно менять в медиазапросах и через JavaScript: `el.style.setProperty('--brand', 'red')`.
