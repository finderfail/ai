# CSS：よくあるミス

- **スタイルが効かない**：より詳細度の高いセレクターか、後のルールに上書きされている。DevTools の Styles で確認する。
- **幅が想定より大きい**：`box-sizing: border-box` がない。
- **`height: 100%` が効かない**：親に高さがない。`min-height: 100vh` か flex/grid を使う。
- **スマホで横スクロールが出る**：画面より広い要素（スクロールバー込みの `width: 100vw`、固定幅）。`max-width: 100%` を使う。
- **`z-index` が効かない**：位置指定されていないか、別の重ね合わせコンテキストにある。
- **`margin: auto` で縦に中央寄せできない**：通常の流れではできない。flex/grid を使う。
- **マージンの相殺**：子のマージンが親の外に「はみ出す」。`padding` か `display: flow-root` で防ぐ。
- **画像の下に隙間**：`img` はインライン要素。`display: block` にする。
- **スマホでメディアクエリが効かない**：`<meta name="viewport">` がない。
