# CSS: селекторы

```css
p { }                    /* по тегу */
.card { }                /* по классу */
#header { }              /* по id */
* { }                    /* все элементы */
nav a { }                /* потомок */
ul > li { }              /* прямой потомок */
h2 + p { }               /* соседний следующий */
h2 ~ p { }               /* все следующие соседи */
a[href] { }              /* есть атрибут */
a[href^="https"] { }     /* начинается с */
a[href$=".pdf"] { }      /* заканчивается на */
li:first-child, li:last-child { }
li:nth-child(2n+1) { }   /* нечётные */
input:not([disabled]) { }
:is(h1, h2, h3) a { }    /* группировка, специфичность по самому сильному */
:where(.btn) { }         /* группировка с нулевой специфичностью */
.card:has(img) { }       /* родитель, у которого есть img */
```

Атрибуты с `^=`, `$=`, `:nth-child`, `:not`, `~` — CSS3; `:is`, `:where`, `:has` — Selectors Level 4, есть во всех современных браузерах.
