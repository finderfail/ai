# 決済ブランドの比較

| ブランド | 国 | モデル | 3-D Secure | セキュリティコード |
|---|---|---|---|---|
| Visa | 米国 | 4者 | Visa Secure | CVV2、3桁 |
| Mastercard | 米国 | 4者 | Identity Check | CVC2、3桁 |
| American Express | 米国 | 3者 | SafeKey | CID、4桁 |
| Discover | 米国 | 米国内は3者 | ProtectBuy | CID、3桁 |
| Diners Club | 米国 | 3者（Discover のネットワーク） | ProtectBuy | 3桁 |
| JCB | 日本 | 日本国内は3者 | J/Secure | CAV2、3桁 |
| UnionPay | 中国 | 4者 | UnionPay 3-D Secure | CVN2、3桁 |
| Mir | ロシア | 4者 | Mir Accept | CVP2、3桁 |
| Belkart | ベラルーシ | 4者 | — | 3桁 |

世界で最も広く使えるのは Visa と Mastercard。AmEx、Discover、Diners、JCB は手数料が高くネットワークが小さいため、使える店が少なめ。UnionPay は中国、Mir はロシア、Belkart はベラルーシで主流です。
