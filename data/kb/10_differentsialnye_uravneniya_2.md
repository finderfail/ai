# Обыкновенные дифференциальные уравнения (введение) — часть 2

### Пример

Решить $y' = xy$.

$$\frac{dy}{y} = x\,dx \Rightarrow \ln|y| = \frac{x^2}{2} + C_1 \Rightarrow y = C e^{x^2/2}$$

## Линейные уравнения первого порядка

Уравнение вида $y' + p(x) y = q(x)$ решается методом интегрирующего множителя $\mu(x) = e^{\int p(x)dx}$:
$$y = \frac{1}{\mu(x)}\left(\int \mu(x) q(x)\,dx + C\right)$$

Альтернативный метод — метод Бернулли (подстановка $y = uv$).

## Линейные однородные уравнения второго порядка с постоянными коэффициентами

Уравнение вида $y'' + py' + qy = 0$. Составляют характеристическое уравнение:
$$k^2 + pk + q = 0$$

В зависимости от дискриминанта $D = p^2 - 4q$:

- $D > 0$: два действительных корня $k_1, k_2$, общее решение $y = C_1 e^{k_1 x} + C_2 e^{k_2 x}$;
- $D = 0$: один корень $k$ кратности 2, $y = (C_1 + C_2 x)e^{kx}$;
- $D < 0$: комплексные корни $k = \alpha \pm i\beta$, $y = e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$.
