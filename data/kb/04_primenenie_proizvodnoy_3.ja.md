# 導関数による関数の調べ方 — その3

## 凹凸と変曲点

- $f''(x) > 0$ — グラフは下に凸。
- $f''(x) < 0$ — グラフは上に凸。
- 2階導関数の符号が変わる点を **変曲点** といいます。

## 閉区間での最大値と最小値

連続関数の閉区間 $[a, b]$ での最大値と最小値を求めるには：

1. 区間 $(a, b)$ 内の臨界点を求める。
2. 臨界点と両端 $a$、$b$ での関数の値を計算する。
3. 得られた値を比べ、最大と最小がそれぞれ求める値。

## 例

関数 $f(x) = x^3 - 3x$ の極値を調べます。

$f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 0 \Rightarrow x = \pm 1$

$x < -1$ で $f'(x) > 0$（増加）、$-1 < x < 1$ で $f'(x) < 0$（減少）、$x > 1$ で $f'(x) > 0$（増加）。

よって $x = -1$ は極大点（$f(-1) = 2$）、$x = 1$ は極小点（$f(1) = -2$）です。
