# 不定積分 — その1

## 定義

区間内のすべての $x$ について $F'(x) = f(x)$ が成り立つとき、関数 $F(x)$ をその区間における $f(x)$ の原始関数といいます。

$f(x)$ のすべての原始関数の集まりを不定積分といい、次のように書きます：
$$\int f(x)\, dx = F(x) + C$$

ここで $C$ は任意の定数（積分定数）です。

## 不定積分の性質

1. $\left(\int f(x)\,dx\right)' = f(x)$
2. $\int f'(x)\,dx = f(x) + C$
3. $\int (f(x) \pm g(x))\,dx = \int f(x)\,dx \pm \int g(x)\,dx$
4. $\int c \cdot f(x)\,dx = c \int f(x)\,dx$（$c$ は定数）
