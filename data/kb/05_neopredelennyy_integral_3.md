# Неопределённый интеграл — часть 3

## Метод интегрирования по частям

$$\int u\,dv = uv - \int v\,du$$

Применяется, когда подынтегральное выражение — произведение функций разной природы (многочлен на экспоненту, многочлен на логарифм, многочлен на тригонометрическую функцию и т.п.). Правило выбора $u$: ЛИАТЭ — логарифмические, обратные тригонометрические, алгебраические (многочлены), тригонометрические, экспоненциальные — в порядке предпочтения для $u$.

## Пример: замена переменной

Вычислить $\int 2x \cdot e^{x^2}\,dx$.

Пусть $u = x^2$, тогда $du = 2x\,dx$:
$$\int 2x \cdot e^{x^2}\,dx = \int e^u\,du = e^u + C = e^{x^2} + C$$

## Пример: интегрирование по частям

Вычислить $\int x \cos x\,dx$.

Пусть $u = x$, $dv = \cos x\,dx$, тогда $du = dx$, $v = \sin x$:
$$\int x\cos x\,dx = x\sin x - \int \sin x\,dx = x\sin x + \cos x + C$$
