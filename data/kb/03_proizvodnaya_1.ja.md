# 関数の導関数 — その1

## 定義

点 $x$ における関数 $f(x)$ の導関数（微分係数）とは、引数の増分を0に近づけたときの、関数の増分と引数の増分の比の極限です：

$$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$

幾何学的な意味：導関数は、その点におけるグラフの接線の傾きに等しい。

物理的な意味：位置の時間微分は瞬間速度、速度の時間微分は加速度。

## 初等関数の導関数の表

| 関数 | 導関数 |
|---|---|
| $c$（定数） | $0$ |
| $x^n$ | $n x^{n-1}$ |
| $\sqrt{x}$ | $\dfrac{1}{2\sqrt{x}}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $\dfrac{1}{x}$ |
| $\log_a x$ | $\dfrac{1}{x \ln a}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\dfrac{1}{\cos^2 x}$ |
| $\cot x$ | $-\dfrac{1}{\sin^2 x}$ |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^2}}$ |
| $\arctan x$ | $\dfrac{1}{1+x^2}$ |
