# Неопределённый интеграл — часть 1

## Определение

Функция $F(x)$ называется первообразной для функции $f(x)$ на промежутке, если $F'(x) = f(x)$ для всех $x$ из этого промежутка.

Совокупность всех первообразных функции $f(x)$ называется неопределённым интегралом и обозначается:
$$\int f(x)\, dx = F(x) + C$$

где $C$ — произвольная постоянная.

## Свойства неопределённого интеграла

1. $\left(\int f(x)\,dx\right)' = f(x)$
2. $\int f'(x)\,dx = f(x) + C$
3. $\int (f(x) \pm g(x))\,dx = \int f(x)\,dx \pm \int g(x)\,dx$
4. $\int c \cdot f(x)\,dx = c \int f(x)\,dx$, где $c$ — константа
