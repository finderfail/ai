# Производная функции — часть 1

## Определение

Производной функции $f(x)$ в точке $x$ называется предел отношения приращения функции к приращению аргумента, когда приращение аргумента стремится к нулю:

$$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$

Геометрический смысл: производная равна угловому коэффициенту касательной к графику функции в данной точке.

Физический смысл: производная пути по времени — это мгновенная скорость; производная скорости по времени — ускорение.

## Таблица производных элементарных функций

| Функция | Производная |
|---|---|
| $c$ (константа) | $0$ |
| $x^n$ | $n x^{n-1}$ |
| $\sqrt{x}$ | $\dfrac{1}{2\sqrt{x}}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $\dfrac{1}{x}$ |
| $\log_a x$ | $\dfrac{1}{x \ln a}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\dfrac{1}{\cos^2 x}$ |
| $\cot x$ | $-\dfrac{1}{\sin^2 x}$ |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^2}}$ |
| $\arctan x$ | $\dfrac{1}{1+x^2}$ |
