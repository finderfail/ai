# Производная функции — часть 3

## Пример

Найти производную функции $f(x) = x^2 \cdot \sin x$.

По правилу произведения:
$$f'(x) = (x^2)' \sin x + x^2 (\sin x)' = 2x \sin x + x^2 \cos x$$

## Пример с цепным правилом

Найти производную $f(x) = \sin(3x^2 + 1)$.

Внешняя функция $\sin(u)$, внутренняя $u = 3x^2+1$:
$$f'(x) = \cos(3x^2+1) \cdot (3x^2+1)' = \cos(3x^2+1) \cdot 6x = 6x\cos(3x^2+1)$$
