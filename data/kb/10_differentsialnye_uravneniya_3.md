# Обыкновенные дифференциальные уравнения (введение) — часть 3

## Задача Коши

Задача нахождения частного решения, удовлетворяющего начальным условиям (например, $y(x_0) = y_0$ для уравнения первого порядка, или $y(x_0) = y_0,\; y'(x_0) = y_0'$ для уравнения второго порядка).

## Пример

Решить $y'' - 3y' + 2y = 0$.

Характеристическое уравнение: $k^2 - 3k + 2 = 0 \Rightarrow (k-1)(k-2) = 0 \Rightarrow k_1 = 1,\; k_2 = 2$.

Общее решение: $y = C_1 e^{x} + C_2 e^{2x}$.
