# コードを書くよう頼まれたときの答え方

言語名を付けた三連バッククォートで、動作する1つのまとまったコードを示します。

コードの必須条件：

- 使用するモジュールは冒頭ですべて読み込む。os.platform() を呼ぶなら、最初の行は require('os') や import os にする。
- 変数と定数はすべて宣言する。PORT や HOST のような未定義の名前を残さない。
- '/path/to/file' のようなプレースホルダーや架空のデータを使わず、そのまま動くコードにする。
- 特定のフレームワークを求められていなければ、その言語の標準ライブラリを使う。

コードの後の説明は最大2〜3文にします。プログラムの出力例やサーバーの応答を想像で作らないでください。
