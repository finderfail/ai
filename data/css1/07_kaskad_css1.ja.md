# CSS1：カスケード、継承、!important

**継承**：多くのプロパティ（フォント、色）は親から子孫へ受け継がれる。

**CSS1 のカスケード**（ルールを選ぶ順序）：
1. 要素とプロパティに対するすべての宣言を見つける。
2. `! important` 付きの宣言は通常の宣言より強い。**CSS1 では** 作者の `!important` がユーザーの `!important` より強かった（CSS2 で逆に変更）。
3. 作者のスタイルはユーザーのスタイルより強く、ユーザーのスタイルはブラウザのスタイルより強い。
4. 詳細度で並べる：（ID の数、クラスと疑似クラスの数、タグの数）。
5. 同じなら後に書いた宣言が勝つ。

```css
P { color: gray ! important }
P#note { color: red }          /* 色には適用されない。前者が !important のため */
```

CSS1 では、インラインの `STYLE` 属性は ID セレクターと同じ詳細度だった。
