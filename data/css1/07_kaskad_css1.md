# CSS1: каскад, наследование, !important

**Наследование**: многие свойства (шрифт, цвет) передаются от родителя к потомкам.

**Каскад в CSS1** — порядок выбора правила:
1. Найти все объявления для элемента и свойства.
2. Объявления с `! important` сильнее обычных. **В CSS1** `!important` автора был сильнее `!important` пользователя (в CSS2 это поменяли наоборот).
3. Стили автора сильнее пользовательских, те — сильнее стилей браузера.
4. Сортировка по специфичности: (число ID, число классов и псевдоклассов, число тегов).
5. При равенстве побеждает объявление, указанное позже.

```css
P { color: gray ! important }
P#note { color: red }          /* не применится к цвету — у первого !important */
```

Inline-атрибут `STYLE` в CSS1 имел специфичность как у ID-селектора.
