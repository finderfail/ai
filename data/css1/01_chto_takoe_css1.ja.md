# CSS1（CSS Level 1）とは

**CSS1** は W3C のカスケーディングスタイルシートの最初の仕様で、**1996年12月17日** に勧告された。著者はホーコン・ウィウム・リーとバート・ボス。

CSS1 でできたこと：
- フォント、色と背景、テキストのプロパティ；
- ボックスモデル：`margin`、`padding`、`border`、`width`、`height`、`float`、`clear`；
- `display`（block、inline、list-item、none）、`white-space`、リストのスタイル；
- タグ、クラス、ID、子孫のセレクター、リンクの疑似クラス、最初の行・文字の疑似要素；
- カスケード、継承、`!important`。

CSS1 に **なかった** もの：位置指定（`position`、`top`、`z-index`）、`:hover`、メディアタイプ、`>` と `+` のセレクター、属性セレクター、flexbox/grid、角丸、影、アニメーション、変数。これらは CSS2 と CSS3 で追加された。

CSS1 はとうに古くなり、CSS2.1 と CSS3 のモジュールに置き換えられた。W3C は CSS1 の仕様を廃止扱いにしている。
