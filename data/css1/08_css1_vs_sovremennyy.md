# CSS1 и современный CSS: отличия

| Задача | CSS1 (1996) | Современный CSS |
|---|---|---|
| Колонки | `float` | flexbox, grid |
| Позиционирование | нет | `position`, `z-index` |
| Наведение | нет `:hover` | `:hover`, `:focus-visible` |
| Скругления, тени | нет | `border-radius`, `box-shadow` |
| Прозрачность | нет | `opacity`, `rgba`, `/ alpha` |
| Адаптивность | нет | медиазапросы, `clamp()` |
| Шрифты с сервера | нет | `@font-face` |
| Переменные | нет | `--var`, `var()` |
| Анимации | нет | `transition`, `@keyframes` |
| Селекторы | тег, класс, ID, потомок | `>`, `+`, `~`, атрибуты, `:nth-child`, `:has()` |

Если пользователь просит код «на CSS1», используй только возможности CSS1 и предупреди, что для современных сайтов этот стандарт не применяется.
