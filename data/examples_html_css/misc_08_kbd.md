# Пример HTML/CSS: отображение клавиш

Стиль для kbd как у настоящих клавиш.

```html
<p>Press <kbd>Ctrl</kbd> + <kbd>K</kbd></p>
```

```css
kbd { display: inline-block; padding: 2px 6px; border: 1px solid #d1d5db; border-bottom-width: 3px;
  border-radius: 6px; background: #f9fafb; font: 12px ui-monospace, monospace; }
```
