# Пример HTML/CSS: страница 404

Центрированное сообщение и кнопка на главную.

```html
<main class="nf"><h1>404</h1><p>Page not found</p><a href="/">Go home</a></main>
```

```css
.nf { min-height: 100dvh; display: grid; place-content: center; text-align: center; gap: 8px; }
.nf h1 { margin: 0; font-size: clamp(64px, 15vw, 160px); line-height: 1;
  background: linear-gradient(90deg, #6366f1, #ec4899); -webkit-background-clip: text; background-clip: text; color: transparent; }
.nf a { justify-self: center; margin-top: 12px; padding: 10px 20px; border-radius: 10px; background: #111; color: #fff; text-decoration: none; }
```
