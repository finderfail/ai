# Пример HTML/CSS: градиентная рамка

Рамка-градиент со скруглением.

```html
<div class="gb">Premium</div>
```

```css
.gb { padding: 20px; border: 2px solid transparent; border-radius: 16px;
  background: linear-gradient(#fff, #fff) padding-box, linear-gradient(90deg, #6366f1, #ec4899) border-box; }
```
