# Qwen2.5-Instruct Fine-Tuning + Russian Conversational Speech RAG — часть 25

# 34. Catastrophic forgetting

Слишком агрессивный fine-tune может ухудшить способности базовой модели.

Например, после обучения на узком разговорном dataset модель может хуже:

- следовать сложным инструкциям;
- писать структурированный текст;
- использовать технические термины;
- переключаться между стилями.

Это одна из причин, почему dataset должен быть разнообразным.

# 35. Learning rate

Learning rate сильно влияет на силу изменения поведения.

Слишком высокий:

- быстрый drift;
- сильное изменение поведения;
- риск overfitting;
- потеря исходных способностей.

Слишком низкий:

- эффект fine-tune может быть слабым;
- потребуется больше шагов.

Для LoRA часто начинают с диапазона порядка `1e-5`–`2e-4`, но универсального значения нет.

Конкретное значение зависит от:

- размера модели;
- размера dataset;
- количества эпох;
- rank;
- качества данных;
- цели обучения.
