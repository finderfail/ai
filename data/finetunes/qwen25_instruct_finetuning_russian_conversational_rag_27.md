# Qwen2.5-Instruct Fine-Tuning + Russian Conversational Speech RAG — часть 27

# 38. Sequence length

Слишком маленький context может обрезать multi-turn примеры.

Слишком большой context:

- увеличивает потребление памяти;
- уменьшает количество примеров на единицу VRAM;
- может быть неоправданным для коротких диалогов.

Если основная задача — чат, полезно иметь много коротких и средних примеров, а не только гигантские conversations.

---

# 39. Padding и packing

Training pipeline может использовать packing нескольких коротких примеров в одну последовательность.

Это может повысить эффективность.

Но важно понимать, как именно конкретный trainer обрабатывает:

- EOS;
- attention mask;
- chat template;
- labels.

Нельзя blindly копировать конфигурацию из другого проекта.
