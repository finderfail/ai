# Qwen2.5-Instruct Fine-Tuning + Russian Conversational Speech RAG — часть 42

# 60. Короткая итоговая формула

Для conversational Qwen:

`хорошие реальные примеры > огромное количество примеров`

`разнообразие > повторение`

`контекст > отдельная фраза`

`естественность > намеренный сленг`

`RAG для знаний`

`fine-tuning для поведения`

`evaluation > субъективное ощущение`

Именно такая схема обычно даёт гораздо более устойчивый результат, чем попытка «запихнуть разговорность» через тысячи одинаковых сообщений.
