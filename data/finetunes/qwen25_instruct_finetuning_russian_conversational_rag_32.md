# Qwen2.5-Instruct Fine-Tuning + Russian Conversational Speech RAG — часть 32

# 45. RAG и разговорный стиль

Очень полезный вариант:

RAG хранит:

```text
официальные факты
документацию
FAQ
технические инструкции
```

Fine-tune хранит:

```text
как объяснять
какой длины отвечать
насколько формально писать
как вести диалог
как реагировать на короткие сообщения
```

Например:

RAG находит:

> «Белкарт — национальная платёжная система Беларуси...»

Fine-tune может заставить модель объяснить:

> «Если коротко, Белкарт — это белорусская платёжная система. По сути, местный карточный платёжный контур.»

Факты пришли из RAG, манера ответа — из fine-tuning.

---

# 46. Fine-tuning не должен превращаться в memory dump

Не стоит использовать fine-tuning как замену базе данных.

Если в dataset находятся 10000 фактов, которые модель должна точно цитировать, возможны:

- hallucinations;
- устаревание;
- неправильное запоминание;
- смешивание похожих фактов.

Для таких данных лучше RAG.
