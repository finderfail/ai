# 57. Минимальный checklist dataset

Перед обучением:

- [ ] JSONL валиден.
- [ ] Каждая запись содержит messages.
- [ ] Роли корректны.
- [ ] Нет секретов и PII.
- [ ] Нет массовых дубликатов.
- [ ] Есть короткие ответы.
- [ ] Есть средние ответы.
- [ ] Есть длинные ответы.
- [ ] Есть multi-turn.
- [ ] Есть нейтральная речь.
- [ ] Есть casual-речь.
- [ ] Сленг не используется искусственно.
- [ ] Мат не является обязательным.
- [ ] Есть validation set.
- [ ] Benchmark не пересекается с train.
