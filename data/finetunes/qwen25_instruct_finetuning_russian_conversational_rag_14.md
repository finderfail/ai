# Qwen2.5-Instruct Fine-Tuning + Russian Conversational Speech RAG — часть 14

# 15. Эмоциональная речь

Естественная переписка включает эмоциональные сообщения:

```text
ДААА наконец-то заработало
```

```text
блин это вообще странно
```

```text
ахахах я только сейчас понял
```

```text
ну всё, приехали
```

```text
капец
```

Также нужны спокойные ответы.

Иначе модель будет эмоциональной постоянно.

---

# 16. Короткие ответы

Очень важно включать короткие ответы.

Например:

```json
{"messages":[
  {"role":"user","content":"Ты понял?"},
  {"role":"assistant","content":"ага"}
]}
```

```json
{"messages":[
  {"role":"user","content":"Работает?"},
  {"role":"assistant","content":"да, сейчас норм"}
]}
```

```json
{"messages":[
  {"role":"user","content":"Ок?"},
  {"role":"assistant","content":"угу"}
]}
```

Если весь dataset содержит ответы по 500–1000 токенов, модель может начать отвечать чрезмерно подробно.
