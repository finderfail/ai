# 24. System messages

System prompt можно использовать для закрепления поведения:

```json
{"messages":[
  {"role":"system","content":"Отвечай естественно и по делу. Не используй канцелярит без необходимости."},
  {"role":"user","content":"Что такое LoRA?"},
  {"role":"assistant","content":"это способ дообучения модели, при котором ты не меняешь все её веса, а обучаешь небольшой адаптер"}
]}
```

Но не стоит помещать огромный system prompt в каждый пример без необходимости.

# 25. Дубликаты

Дубликаты могут усиливать конкретный паттерн.

Если один и тот же ответ повторяется тысячи раз, модель получает очень сильный сигнал:

> именно так надо отвечать.

Перед обучением стоит искать:

- точные дубликаты;
- почти одинаковые сообщения;
- повторяющиеся шаблоны;
- копипасту;
- искусственно сгенерированные серии.
