# Qwen2.5-Instruct Fine-Tuning + Russian Conversational Speech RAG — часть 19

# 23. Multi-turn особенно важен

Плохо:

```text
user -> assistant
user -> assistant
user -> assistant
```

если каждый пример полностью независим.

Лучше иногда давать контекст:

```json
{"messages":[
  {"role":"user","content":"Я хочу дообучить Qwen."},
  {"role":"assistant","content":"Окей. А что именно хочешь изменить — знания, стиль или поведение?"},
  {"role":"user","content":"Стиль общения."},
  {"role":"assistant","content":"тогда я бы не пытался просто залить туда сленг. лучше собрать разнообразную разговорную речь и следить, чтобы модель не переучилась на одном паттерне"},
  {"role":"user","content":"а мат добавлять?"},
  {"role":"assistant","content":"можно, если он реально встречается в целевом стиле. только не делай его обязательной частью каждого ответа"}
]}
```

Так модель обучается не только отдельным ответам, но и динамике диалога.
