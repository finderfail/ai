# Qwen2.5-Instruct Fine-Tuning + Russian Conversational Speech RAG — часть 5

# 3. LoRA

LoRA — Low-Rank Adaptation.

Вместо изменения всех параметров исходной модели добавляются небольшие обучаемые матрицы.

Преимущества:

- намного меньше обучаемых параметров;
- меньше VRAM;
- быстрее обучение;
- базовую модель можно оставить неизменной;
- один base model можно использовать с несколькими LoRA.

Типичные параметры:

- `r` — rank;
- `lora_alpha` — масштаб адаптера;
- `lora_dropout`;
- `target_modules`.

Больший rank даёт адаптеру больше ёмкости, но увеличивает количество обучаемых параметров.

Для первого эксперимента разумнее начать с умеренного rank, например 8–32, и смотреть на результат, а не сразу использовать максимально большие значения.
