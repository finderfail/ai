# HTML 3.2 и HTML5: отличия

| Задача | HTML 3.2 (1997) | HTML5 |
|---|---|---|
| Доктайп | длинный с DTD | `<!DOCTYPE html>` |
| Оформление | `<FONT>`, `<CENTER>`, `BGCOLOR` | CSS |
| Раскладка | таблицы | CSS grid, flexbox |
| Семантика | нет | `<header>`, `<main>`, `<article>`, `<nav>` |
| Видео/аудио | плагины | `<video>`, `<audio>` |
| Графика | GIF, апплеты | SVG, `<canvas>` |
| Формы | без валидации | `required`, `type="email"`, `<label>` |
| Скрипты | зарезервированы | `<script>`, `defer`, модули |
| Регистр тегов | обычно ЗАГЛАВНЫЕ | строчные |

Если пользователь просит код «на HTML 3.2» или «в стиле 90-х», используй только элементы и атрибуты HTML 3.2 и предупреди, что для современных сайтов так не делают.
