# HTML 3.2 とは

- **HTML 3.2** は **1997年1月14日** の W3C 勧告（コードネーム Wilbur）。Netscape Navigator と Internet Explorer がすでに対応していた機能を標準化した。
- **HTML 3.0**（1995年）は表、数式、図を含む草案だったが標準にはならず、ブラウザもほとんど実装しなかった。
- 1年後、HTML 3.2 は **HTML 4.0**（1997年12月）に置き換えられ、その後 HTML 4.01、XHTML、HTML5 が続いた。

HTML 3.2 の文書型宣言：
```html
<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 3.2 Final//EN">
```

3.2 で追加されたもの：表、Java アプレット（`<APPLET>`）、画像の回り込み、`<FONT>`、`<CENTER>`、上付き・下付き文字、クライアントサイドのイメージマップ（`<MAP>`）、`<BODY>` の色属性。`<SCRIPT>` と `<STYLE>` は将来のために予約されただけだった。

当時はタグを **大文字** で書くのが一般的で、属性の引用符はよく省略された。
