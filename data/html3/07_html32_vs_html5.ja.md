# HTML 3.2 と HTML5 の違い

| やりたいこと | HTML 3.2（1997年） | HTML5 |
|---|---|---|
| 文書型宣言 | DTD 付きの長いもの | `<!DOCTYPE html>` |
| 装飾 | `<FONT>`、`<CENTER>`、`BGCOLOR` | CSS |
| レイアウト | 表 | CSS grid、flexbox |
| セマンティクス | なし | `<header>`、`<main>`、`<article>`、`<nav>` |
| 動画・音声 | プラグイン | `<video>`、`<audio>` |
| グラフィック | GIF、アプレット | SVG、`<canvas>` |
| フォーム | 検証なし | `required`、`type="email"`、`<label>` |
| スクリプト | 予約のみ | `<script>`、`defer`、モジュール |
| タグの大文字小文字 | 普通は大文字 | 小文字 |

ユーザーが「HTML 3.2 で」や「90年代風に」コードを求めたら、HTML 3.2 の要素と属性だけを使い、現代のサイトではそうしないと伝えること。
