# HTML5: частые ошибки

- **Нет `<!DOCTYPE html>`** — браузер включает режим совместимости, вёрстка «едет».
- **Нет `<meta name="viewport">`** — сайт на телефоне показывается уменьшенной копией десктопа.
- **`<div>` вместо `<button>`** — элемент недоступен с клавиатуры и скринридеру.
- **Картинки без `alt`**, поля формы без `<label>`.
- **Блочный элемент внутри строчного**: `<p>` внутри `<span>`; `<div>` внутри `<p>` — браузер «закроет» абзац.
- **Повторяющиеся `id`** — `id` должен быть уникальным на странице.
- **Таблицы для раскладки** вместо CSS grid/flex.
- **`<br>` для отступов** — используйте CSS `margin`.
- **`target="_blank"` без `rel="noopener"`** в старых браузерах давал открытой странице доступ к вашей.
- **Скрипты в `<head>` без `defer`** блокируют отрисовку.
- **Заголовки ради размера шрифта** (`<h3>` вместо стиля) ломают структуру документа.

Проверка разметки: validator.w3.org, Lighthouse в Chrome DevTools.
