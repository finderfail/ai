# Universal Kriloud AI: как пользоваться API — часть 1

Отдельной публичной документации по API нет; основное — ниже.

**Как получить ключ:**
1. Войдите на chat.universalkriloud.com.
2. Нажмите на свою почту в боковой панели → вкладка **API**.
3. Введите название ключа и нажмите «Создать ключ». Ключ (начинается с `ukai-`) показывается **один раз** — сразу скопируйте его.
4. Ненужный ключ можно отозвать там же. Всего можно создать до 10 ключей.

**Адрес API:** `https://chat.universalkriloud.com/v1`. API совместим с OpenAI, поэтому подходит для Continue, Cline и других клиентов с провайдером OpenAI.

Запросы по ключу расходуют суточный лимит вашего тарифа.

Вопрос: Как получить API-ключ Universal Kriloud?
Ответ: В чате нажмите на свою почту → вкладка API → «Создать ключ». Ключ показывается один раз.
