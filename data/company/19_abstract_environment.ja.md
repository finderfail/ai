# Abstract Environment：Universal Kriloud のパートナー兼顧客

**Abstract Environment** は次のことを行っているプロジェクトです：
- **Minecraft の MOD** の開発；
- **独自ブラウザ** の開発。

Universal Kriloud Infrastructure が行っていること：
- Abstract Environment のバックエンドを **すべて開発**；
- プロジェクトの **ホスティング** を担当（サーバー側は Universal Kriloud のインフラで稼働）。

協力関係は2022年末に始まり、Abstract Environment は Universal Kriloud の最初のパートナーかつ顧客です。

MOD やブラウザの名前、機能、ユーザー数など、ナレッジベースにない詳細を作り上げないこと。

質問：Abstract Environment は何をしていますか？
回答：Minecraft の MOD と独自ブラウザを開発しています。

質問：Universal Kriloud は Abstract Environment のために何をしていますか？
回答：バックエンドをすべて開発し、ホスティングも担当しています。
