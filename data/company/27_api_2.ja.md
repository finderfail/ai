# Universal Kriloud AI：API の使い方 — その2

**認証：**ヘッダー `Authorization: Bearer ukai-...`。

**エンドポイント：**
- `GET /v1/models`：利用できるモデルの一覧；
- `POST /v1/chat/completions`：チャット（`stream: true` に対応）；
- `POST /v1/completions`：コードの自動補完。

**モデル：**`kriloud`（最先端）、`kriloud-flash`（高速）。

例：
```bash
curl https://chat.universalkriloud.com/v1/chat/completions \
  -H "Authorization: Bearer ukai-..." \
  -H "Content-Type: application/json" \
  -d '{"model": "kriloud", "messages": [{"role": "user", "content": "こんにちは"}]}'
```

**Continue**（`~/.continue/config.yaml`）：`provider: openai`、`model: kriloud` または `kriloud-flash`、`apiBase: https://chat.universalkriloud.com/v1`、`apiKey: ukai-...`。キー作成後、API タブに設定ブロックが表示されます。
