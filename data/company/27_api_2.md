# Universal Kriloud AI: как пользоваться API — часть 2

**Авторизация:** заголовок `Authorization: Bearer ukai-...`.

**Эндпоинты:**
- `GET /v1/models` — список доступных моделей;
- `POST /v1/chat/completions` — чат (поддерживается `stream: true`);
- `POST /v1/completions` — автодополнение кода.

**Модели:** `kriloud` — передовая, `kriloud-flash` — быстрая.

Пример:
```bash
curl https://chat.universalkriloud.com/v1/chat/completions \
  -H "Authorization: Bearer ukai-..." \
  -H "Content-Type: application/json" \
  -d '{"model": "kriloud", "messages": [{"role": "user", "content": "Привет"}]}'
```

**Continue** (`~/.continue/config.yaml`): `provider: openai`, `model: kriloud` или `kriloud-flash`, `apiBase: https://chat.universalkriloud.com/v1`, `apiKey: ukai-...`. Готовый блок конфигурации есть на вкладке API после создания ключа.
