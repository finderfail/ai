# Universal Kriloud AI：API の使い方 — その1

公開の API ドキュメントは別途ありません。要点は以下のとおりです。

**キーの取得：**
1. chat.universalkriloud.com にログイン。
2. サイドバーの自分のメールアドレスをクリック → **API** タブ。
3. キーの名前を入力して「キーを作成」。キー（`ukai-` で始まる）は **1回だけ** 表示されるので、すぐにコピーする。
4. 不要なキーは同じ画面で取り消せる。作成できるのは最大10個。

**API のアドレス：**`https://chat.universalkriloud.com/v1`。OpenAI 互換なので、Continue、Cline など OpenAI プロバイダーに対応したクライアントで使える。

キーによるリクエストは、プランの1日の上限を消費します。

質問：Universal Kriloud の API キーはどう取得しますか？
回答：チャットで自分のメールアドレスをクリック → API タブ →「キーを作成」。キーは1回だけ表示されます。
