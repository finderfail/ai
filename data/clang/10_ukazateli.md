# Указатели

```c
int value = 42;
int *ptr = &value;

printf("%d\n", *ptr);
printf("%p\n", (void *)ptr);

*ptr = 100;

int *null_ptr = NULL;
if (null_ptr != NULL) {
    printf("%d\n", *null_ptr);
}
```

`&` берёт адрес переменной, `*` разыменовывает указатель. Разыменование `NULL` или неинициализированного указателя роняет программу.

Указатель и массив тесно связаны: имя массива в выражении превращается в указатель на первый элемент.

```c
int arr[3] = {10, 20, 30};
int *p = arr;
printf("%d %d\n", p[1], *(p + 2));
```
