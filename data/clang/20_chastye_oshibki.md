# Частые ошибки в C

**Утечка памяти** — выделили через `malloc`, забыли `free`.

**Использование после освобождения** — обращение к указателю после `free`. Лечится присваиванием `NULL`.

**Выход за границы массива** — `int a[5]; a[5] = 1;` затирает чужую память. Индексы идут от 0 до N-1.

**Переполнение буфера** — `strcpy` в слишком маленький массив. Используйте `snprintf` с указанием размера.

**Возврат указателя на локальную переменную**:

```c
char *broken(void) {
    char buffer[64];
    return buffer;      /* память исчезнет при выходе из функции */
}
```

**Сравнение строк через `==`** сравнивает адреса, а не содержимое. Нужен `strcmp`.

**Присваивание вместо сравнения**: `if (x = 5)` вместо `if (x == 5)` — компилируется, но всегда истинно.

**Неинициализированные переменные** содержат мусор, а не ноль.
