# C のよくあるミス

**メモリリーク**：`malloc` で確保したのに `free` を忘れる。

**解放後の使用**：`free` の後にポインタを使う。`NULL` を代入して防ぎます。

**配列の範囲外アクセス**：`int a[5]; a[5] = 1;` は他のメモリを壊します。添字は 0 から N-1 です。

**バッファオーバーフロー**：小さすぎる配列への `strcpy`。サイズを指定する `snprintf` を使います。

**ローカル変数へのポインタを返す**：

```c
char *broken(void) {
    char buffer[64];
    return buffer;      /* 関数を抜けるとメモリは無効になる */
}
```

**`==` による文字列比較**は内容ではなくアドレスを比べます。`strcmp` が必要です。

**比較のつもりの代入**：`if (x == 5)` のつもりで `if (x = 5)` と書くと、コンパイルは通りますが常に真になります。

**未初期化の変数**の中身はゼロではなく不定値です。
