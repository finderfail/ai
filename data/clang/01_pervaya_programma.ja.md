# C の最初のプログラム

```c
#include <stdio.h>

int main(void) {
    printf("こんにちは、世界！\n");
    return 0;
}
```

`#include <stdio.h>` は標準入出力を読み込みます。`main` はエントリーポイントで、かっこ内の `void` は引数を受け取らないことを示します。`return 0` は正常終了を OS に伝え、それ以外の値はエラーを意味します。

`\n` は改行です。これがないと出力は同じ行に続きます。

キーワード：C 言語、C、hello world、最初のプログラム、C でプログラミングを始める。
