# Первая программа на C

```c
#include <stdio.h>

int main(void) {
    printf("Привет, мир!\n");
    return 0;
}
```

`#include <stdio.h>` подключает стандартный ввод-вывод. `main` — точка входа, `void` в скобках означает, что программа не принимает аргументов. `return 0` сообщает операционной системе об успешном завершении, любое другое значение означает ошибку.

Символ `\n` — перевод строки. Без него вывод останется в той же строке.

Ключевые слова: язык си, C, hello world, первая программа, начать программировать на си.
