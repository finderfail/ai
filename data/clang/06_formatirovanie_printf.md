# Спецификаторы printf и scanf

| Спецификатор | Тип |
|---|---|
| `%d` | int |
| `%u` | unsigned int |
| `%ld` | long |
| `%lld` | long long |
| `%f` | float, double в printf |
| `%lf` | double в scanf |
| `%c` | char |
| `%s` | строка |
| `%p` | указатель |
| `%zu` | size_t |
| `%x` | шестнадцатеричное |
| `%%` | сам символ процента |

```c
printf("%5d|\n", 42);      /* ширина 5:    42| */
printf("%-5d|\n", 42);     /* влево:     42   | */
printf("%.2f\n", 3.14159); /* два знака:   3.14 */
```

Несовпадение спецификатора и типа аргумента приводит к неопределённому поведению, а не к ошибке компиляции.
