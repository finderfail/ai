# REST API: формат запросов и ответов

- Формат — **JSON**, `Content-Type: application/json; charset=utf-8`.
- Имена полей в одном стиле во всём API: `camelCase` или `snake_case`.
- Даты — строки **ISO 8601** в UTC: `"2026-10-12T14:30:00Z"`.
- Деньги — целым числом в минимальных единицах (`amountMinor: 1999`) или строкой-десятичным числом, плюс код валюты ISO 4217 (`"currency": "JPY"`). Не используйте float для денег.
- Идентификаторы — строки (UUID, ULID) или числа, но единообразно.
- `null` — значение явно отсутствует; лучше не смешивать с отсутствием поля.
- Перечисления — строками: `"status": "paid"`.

Ответ со списком:
```json
{
  "data": [{ "id": "u_1", "email": "a@example.com" }],
  "meta": { "total": 134, "limit": 20, "nextCursor": "eyJpZCI6MjB9" }
}
```

Одиночный ресурс можно отдавать либо как объект, либо в `{ "data": {...} }` — главное, одинаково во всём API.
