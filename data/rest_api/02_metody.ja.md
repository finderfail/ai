# REST API：HTTP メソッド、安全性、冪等性

| メソッド | 用途 | 安全 | 冪等 | 本文 |
|---|---|---|---|---|
| GET | リソースや一覧の取得 | はい | はい | なし |
| HEAD | GET と同じだがヘッダーのみ | はい | はい | なし |
| POST | 作成、処理の実行 | いいえ | いいえ | あり |
| PUT | リソース全体の置き換え | いいえ | はい | あり |
| PATCH | 部分的な更新 | いいえ | 保証なし | あり |
| DELETE | 削除 | いいえ | はい | 通常なし |
| OPTIONS | 機能の確認、CORS プリフライト | はい | はい | なし |

- **安全**：サーバーの状態を変えない。
- **冪等**：同じリクエストを繰り返しても、1回と同じ結果になる。そのためネットワーク障害時に GET、PUT、DELETE はクライアントやプロキシが安全に再試行できるが、POST はできない（冪等キーが必要）。

PUT はリソース全体を送り、含まれないフィールドはリセットされる。PATCH は送ったフィールドだけを変更する（JSON Merge Patch：RFC 7396、JSON Patch：RFC 6902）。
