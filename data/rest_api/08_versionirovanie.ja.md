# REST API：バージョニング

バージョンの指定方法：
- **パス**：`/api/v1/users`。最も一般的で分かりやすい。
- **ヘッダー**：`Accept: application/vnd.example.v2+json` や `API-Version: 2026-10-01`。
- **クエリ**：`?version=2`。あまり使われない。

ルール：
- 新しいメジャーバージョンは **互換性のない** 変更のときだけ：フィールドの削除や名前変更、型の変更、意味の変更。
- 互換性のある変更はバージョンを上げずに行う：任意の新フィールド、新しいエンドポイント、レスポンスの新しい値（クライアントは知らないフィールドを無視すべき）。
- 新版のリリース後も旧版をサポートし、終了時期を告知する：`Deprecation` と `Sunset` ヘッダー、クライアントへの連絡、変更履歴。
- 一部の API（Stripe など）は、顧客アカウントに固定される日付形式のバージョンを使う。
