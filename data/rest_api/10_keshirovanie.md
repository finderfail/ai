# REST API: кеширование и условные запросы

Заголовки:
- `Cache-Control: no-store` — для персональных и чувствительных данных.
- `Cache-Control: public, max-age=300` — публичные данные можно кешировать 5 минут.
- `Cache-Control: private, max-age=60` — кеш только в браузере пользователя.

**ETag и условные запросы**:
```
GET /products/42
200 OK
ETag: "v17"

GET /products/42
If-None-Match: "v17"
304 Not Modified
```
Сервер не отдаёт тело, если ресурс не изменился, — экономия трафика.

**Оптимистическая блокировка**: при обновлении клиент отправляет `If-Match: "v17"`. Если ресурс уже изменили, сервер отвечает **412 Precondition Failed**, и чужие изменения не затираются.

`Last-Modified` / `If-Modified-Since` работают аналогично, но с точностью до секунды.
