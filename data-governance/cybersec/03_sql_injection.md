# SQL-инъекции и защита от них

Уязвимость возникает, когда пользовательский ввод попадает в SQL-запрос как часть кода, а не как данные.

Уязвимый код:

```python
query = f"SELECT * FROM users WHERE email = '{email}'"
cursor.execute(query)
```

Ввод `' OR '1'='1` превращает запрос в условие, истинное для всех строк.

## Правильный способ: параметризованные запросы

```python
cursor.execute("SELECT * FROM users WHERE email = ?", (email,))
```

Драйвер сам экранирует значение, и оно никогда не интерпретируется как SQL.

## Дополнительные меры

- ORM (SQLAlchemy, Django ORM) по умолчанию использует параметризацию.
- Учётная запись приложения должна иметь минимальные права: без DROP, без доступа к чужим схемам.
- Валидация формата на входе (email, число, дата) сокращает поверхность атаки.
- Не показывать текст SQL-ошибок пользователю — они помогают атакующему.

Ключевые слова: SQL-инъекция, sql injection, инъекция в базу данных.
