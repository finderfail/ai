# XSS：クロスサイトスクリプティング — その2

## 対策

HTML に入れる前にユーザー入力をエスケープします：

```javascript
function escapeHtml(str) {
  return str
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;");
}
```

- テキストを入れるときは `innerHTML` ではなく `textContent` を使う。
- Content Security Policy で外部スクリプトやインラインスクリプトの実行を禁止する。
- セッション cookie に `HttpOnly` を付けると JavaScript から盗めなくなる。
- 最近のテンプレートエンジン（React、Vue、Jinja2）は出力を自動でエスケープする。危険なのは `dangerouslySetInnerHTML` のような明示的な回避だけ。

キーワード：XSS、クロスサイトスクリプティング、スクリプトの埋め込み。
