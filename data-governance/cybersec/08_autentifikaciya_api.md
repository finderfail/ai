# Аутентификация и авторизация в API

**Аутентификация** отвечает на вопрос «кто ты», **авторизация** — «что тебе можно».

## Способы

- **API-ключи** — просты, подходят для server-to-server. Хранить только хеш ключа, показывать полное значение один раз при создании.
- **JWT** — самодостаточный токен с подписью. Не хранить в нём секреты: тело читается любым, кто получил токен.
- **OAuth 2.0** — делегирование доступа сторонним приложениям без передачи пароля.

## Правила

- Секреты сравнивать функцией с постоянным временем, а не оператором равенства.
- У токенов должен быть срок жизни и возможность отзыва.
- Проверять права на каждый запрос, а не только при входе: скрытая кнопка в интерфейсе не является защитой.
- Идентификаторы объектов проверять на принадлежность пользователю, иначе получится IDOR — доступ к чужим данным подменой номера в URL.
- Ограничивать частоту запросов по ключу и по адресу.

Ключевые слова: аутентификация, авторизация, API-ключи, JWT, OAuth, IDOR.
