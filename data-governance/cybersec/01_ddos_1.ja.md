# DDoS 攻撃とその対策 — その1

DDoS（Distributed Denial of Service）は分散型サービス妨害攻撃です。多数の感染したマシンが同時にサービスへリクエストを送り、リソースを使い果たさせて正規のユーザーが使えない状態にします。

## 主な種類

- **ボリューム型（volumetric）**：ゴミのトラフィックで回線を埋める。UDP flood、ICMP flood、DNS amplification。規模はギガビット毎秒で測る。
- **プロトコル型**：接続のリソースを使い果たす。SYN flood は半開きの TCP 接続を残し、Slowloris は最小限のトラフィックで HTTP 接続を開いたままにする。
- **アプリケーション層型（L7）**：重いページや API への通常のリクエストを装う。トラフィックが正規に見えるため、最もフィルタしにくい。
