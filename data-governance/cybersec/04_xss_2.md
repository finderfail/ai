# XSS: межсайтовый скриптинг — часть 2

## Защита

Экранирование пользовательского ввода перед вставкой в HTML:

```javascript
function escapeHtml(str) {
  return str
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;");
}
```

- Использовать `textContent` вместо `innerHTML`, когда вставляется текст.
- Content Security Policy запрещает выполнение внешних и inline-скриптов.
- Флаг `HttpOnly` на cookie сессии не даёт украсть её через JavaScript.
- Современные шаблонизаторы (React, Vue, Jinja2) экранируют вывод автоматически — опасны только явные обходы вроде `dangerouslySetInnerHTML`.

Ключевые слова: XSS, межсайтовый скриптинг, внедрение скриптов.
