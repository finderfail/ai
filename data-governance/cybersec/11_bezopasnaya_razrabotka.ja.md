# 安全な開発

## 秘密情報

パスワード、トークン、鍵をリポジトリにコミットしないでください。環境変数やシークレットマネージャー（Vault、AWS Secrets Manager）に保存し、`.env` は `.gitignore` に追加します。

秘密情報が git に入ってしまった場合、新しいコミットで削除するだけでは不十分です。履歴に残るので、**無効化して置き換える**必要があります。

## 依存関係

```bash
npm audit
pip-audit
```

ライブラリを定期的に更新し、使っているパッケージの脆弱性を追い、ロックファイルでバージョンを固定します。

## チェック

- 静的解析（SAST）でコード内の脆弱なパターンを探す。
- 依存関係の分析（SCA）でライブラリの既知の CVE を見つける。
- 入力処理、権限、秘密情報に注意したコードレビュー。
- サービスアカウントには最小権限の原則を適用。
- サーバー側での入力検証は必須。クライアント側の検証は簡単に回避される。

キーワード：安全な開発、秘密情報、依存関係、CVE、コードレビュー。
