# TLS и шифрование трафика

TLS шифрует данные между клиентом и сервером и подтверждает подлинность сервера сертификатом.

## Практика

- Использовать только TLS 1.2 и 1.3; SSLv3, TLS 1.0 и 1.1 отключить.
- Сертификаты выпускать через Let's Encrypt с автопродлением certbot.
- Включить HSTS, чтобы браузер не пробовал незашифрованное соединение.
- Перенаправлять весь HTTP-трафик на HTTPS.

```nginx
server {
    listen 443 ssl http2;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_prefer_server_ciphers off;
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
}

server {
    listen 80;
    return 301 https://$host$request_uri;
}
```

Симметричное шифрование (AES) быстрое и применяется для самих данных, асимметричное (RSA, ECDSA) — для обмена ключами и подписей. TLS сочетает оба: асимметрично согласует сессионный ключ, дальше работает симметрично.

Ключевые слова: TLS, SSL, HTTPS, сертификат, шифрование трафика.
