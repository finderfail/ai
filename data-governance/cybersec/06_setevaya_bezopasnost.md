# Сетевая безопасность

## Базовые принципы

- Закрывать всё, что не нужно снаружи: базы данных, кеши, административные интерфейсы слушают только localhost или внутреннюю сеть.
- Файрвол работает по принципу «запрещено всё, кроме явно разрешённого».
- SSH — только по ключам, с отключённым входом root и парольной аутентификацией.

Пример настройки ufw:

```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow 443/tcp
sudo ufw enable
```

Настройки SSH в `/etc/ssh/sshd_config`:

```
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
```

## Сегментация

Разделение сети на зоны ограничивает распространение атаки: веб-серверы не должны иметь прямого доступа к базам данных других сервисов, а рабочие станции — к продакшену.

Ключевые слова: сетевая безопасность, файрвол, firewall, ufw, SSH, порты.
