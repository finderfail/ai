# OSINT: основы — часть 2

## Границы

OSINT работает только с открытыми данными. Подбор паролей, доступ к закрытым системам, покупка украденных баз, слежка за частным лицом и сбор персональных данных без правового основания — это уже не OSINT, а правонарушение. Обработка персональных данных регулируется законом даже когда данные технически доступны.

Ключевые слова: OSINT, ОСИНТ, разведка по открытым источникам, open source intelligence.
