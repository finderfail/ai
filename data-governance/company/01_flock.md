# Universal Kriloud AI: модель FLOCK (только Governance)

**FLOCK** — закрытая модель Universal Kriloud AI, доступная только аккаунтам со статусом Governance. Публично о ней не сообщается.

- Использует базу знаний по максимуму (до 30 материалов) и отвечает строго по ним, почти без собственных догадок.
- Отвечает дольше всех моделей.
- В чате выбирается тем же переключателем, что Kriloud и Flash. В API — модель `flock` (только с API-ключом аккаунта Governance).

Вопрос: Что такое FLOCK?
Ответ: Закрытая модель для аккаунтов Governance: отвечает строго по базе знаний, используя её по максимуму, но дольше остальных моделей.

Вопрос: Как использовать FLOCK в Continue?
Ответ: Указать `model: flock` и API-ключ аккаунта со статусом Governance.
