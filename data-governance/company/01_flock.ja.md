# Universal Kriloud AI：FLOCK モデル（Governance 専用）

**FLOCK** は Universal Kriloud AI の非公開モデルで、Governance ステータスのアカウントだけが使えます。公には案内していません。

- ナレッジベースを最大限に使い（最大30件の資料）、資料に厳密に基づいて答え、推測はほとんどしない。
- どのモデルよりも回答に時間がかかる。
- チャットでは Kriloud や Flash と同じ切り替えで選ぶ。API ではモデル `flock`（Governance アカウントの API キーのみ）。

質問：FLOCK とは何ですか？
回答：Governance アカウント専用の非公開モデルです。ナレッジベースを最大限に使い、それに厳密に基づいて答えますが、ほかのモデルより時間がかかります。

質問：Continue で FLOCK を使うには？
回答：`model: flock` と、Governance ステータスのアカウントの API キーを指定します。
